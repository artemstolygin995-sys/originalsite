ОРИГИНАЛ — редизайн сайта, версия v10

Основные файлы:
- index.html — главная страница
- privacy.html — политика конфиденциальности
- styles.css — стили и анимации
- script.js — интерактивность и формы
- car-logo.svg — новый спортивный автомобиль в стиле Porsche 911
- favicon.svg — фавикон в том же стиле
- assets/logos/ — монохромные эмблемы марок для фона блока подбора


Формы отправляются через send.php напрямую на parts@ussury.com. На хостинге должен быть включён PHP и настроена функция mail() (или SMTP на уровне хостинга). Почтовое приложение открывается только по клику на карточку parts@ussury.com.
