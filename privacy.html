Политика конфиденциальности

Настоящая политика описывает общие принципы обработки информации, которую посетитель может указать при использовании форм сайта магазина «Оригинал».

1. Какие данные могут обрабатываться

При отправке формы пользователь может указать адрес электронной почты, сведения об автомобиле или технике, VIN/FRAME, сведения о необходимой запчасти и текст обращения.

2. Цель обработки

Данные используются для ответа на запрос, подбора запчастей, уточнения деталей заказа и связи с пользователем.

3. Передача третьим лицам

Информация не должна передаваться третьим лицам без законных оснований, кроме случаев, необходимых для исполнения заказа или предусмотренных законодательством.

4. Срок хранения

Данные следует хранить только в течение срока, необходимого для обработки обращения и исполнения связанных обязательств.

5. Контакты

По вопросам обработки данных можно обратиться по адресу: parts@ussury.com.
